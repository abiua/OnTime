    唤出快捷键

    Alt + Space
    插件管理
    管理已安装插件的启用状态、查看代码与联网范围，或卸载插件。
    服务商配置
    密钥使用 Windows 系统加密保存，不回显已有密钥。编辑时留空保留原密钥。测试连接会向所保存的服务发送一次简短请求，可能产生少量费用。修改表单后请先保存。
    

    本地文件搜索
    安装引导
    1. 打开官方页面，下载适合电脑架构的 Everything 安装版（不要选择 Lite）。
    2. 运行安装程序，按提示配置索引服务；系统授权由安装程序处理。
    3. 在同一页面下载 ES 命令行工具并解压，点击上方“选择 es.exe”。
    4. 启动 Everything，等待首次索引完成，然后重新检测。
    已有便携版？直接选择程序即可。不覆盖现有配置。取消安装后可随时回到这里继续。
